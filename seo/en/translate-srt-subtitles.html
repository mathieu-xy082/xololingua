Understand how SRT subtitle translation works

Important: existing SRT import is not supported

XoloLingua does not support existing SRT import. It generates a new translated SRT from the original MP4. If you only have a subtitle file, you cannot upload or translate that file directly in this studio.

Translating subtitles means preserving a readable file structure while adapting the meaning and length of the text. This guide explains how SRT works and separates that task from the workflow XoloLingua actually offers: starting again from the video’s speech to produce a new translated track.

Read the structure of an SRT cue

Each cue contains a sequence number, a time range and one or more lines of text. A blank line separates it from the next cue. Timestamps use hours, minutes, seconds and milliseconds, with a comma before the milliseconds. The arrow separates the start time from the end time.

This is an illustrative example written to explain the format, not a measured XoloLingua output. The English text and French adaptation deliberately use the same time slots.

Source text · English

1
00:00:01,000 --> 00:00:03,000
Welcome to the workshop.

2
00:00:03,500 --> 00:00:05,500
Let’s begin.

Adaptation · French

1
00:00:01,000 --> 00:00:03,000
Bienvenue à l’atelier.

2
00:00:03,500 --> 00:00:05,500
Commençons.

Keeping timestamps does not automatically make a translation readable: the translated phrase may be longer. Preserve accented characters with UTF-8 encoding, and check the saved file in the player where it will actually be used.

Only have the subtitle file?

Do not rename an SRT to MP4: changing an extension cannot create an audio track. To translate that file while retaining existing timing work, choose a tool that explicitly accepts SRT input. Keep an untouched copy before editing. XoloLingua does not reuse the cues or corrections from an existing subtitle file.

Have the original MP4 instead?

  1. Choose the matching video version. The MP4 must fit the 1 hour and 400 MiB limits. A different edit will not align with the subtitles you already have.
  2. Identify and verify the spoken language. Correct the detected source if needed. The target language must be different from the source: there is no monolingual export.
  3. Segment and generate. The studio transcribes the audio and translates the text. This regenerates subtitles; it does not translate the SRT file you previously prepared.
  4. Download and compare. Open the new SRT beside your reference in an external tool. Do not expect the cue numbers or their boundaries to match the old file exactly.

Check before handing the track over

Proofread names, numbers, meaning and timing. Listen closely around speaker changes and technical explanations. Check accented characters and line breaks after saving, not just while editing. Keep source and translated versions separate so that a correction does not accidentally overwrite your only reliable copy.

Local processing, with practical limits

In the studio, video and audio are processed locally in your browser; models are downloaded from remote services on demand. This is not a promise of fully offline operation. Compatibility depends on your browser, available memory and device capabilities. Not all languages or language pairs are supported, and there is no guaranteed processing time.

Existing SRT import is not supported. There is no built-in editor for corrections, no YouTube URL ingestion and no automatic publishing. Keep your original file and use an external tool when the subtitles need changes. A successful download is the start of your review, not a guarantee that the translation is ready for an audience.
